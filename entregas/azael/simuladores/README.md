## Flujo de entrega

Sube los archivos extraídos, no ZIP/RAR, usando tu cuenta en esta rama. No modifiques main ni archivos de la aplicación. No incluyas entornos virtuales, secretos, datos personales ni respaldos.

Puedes entregar ahora lo disponible y señalar lo faltante. Después abre un pull request en borrador hacia main para recibir retroalimentación. Las correcciones se suben a esta misma rama. No fusiones el PR: Marlon revisará la entrega y su integración.

Estado inicial: espacio preparado; carga del integrante pendiente. Recibir archivos no significa validar ni integrar su contenido. La app no debe importar desde entregas/.
